# Plan the admitted adapter and runtime composition

Type: task
Label: wayfinder:task
Status: open
Blocked by: 01
Parent: [Reusable communication and agent integration](../map.md)

## Question

Bind ratified guarantees to exact components, wire schemas, runtime isolation,
configuration, implementation work and technical proof profiles without a core fork.

## Dependency

Contract review must resolve public responsibility and authority before implementation
planning commits to a realization. This does not depend on a consumer's deployed runtime.

## Planning obligations

Inventory every direct and transitive executable/library/module and its license.
Select SDKs and reuse existing protocol/verification/persistence machinery before custom
infrastructure. Bind launch and ACP credential handling, verified task context, governed
tools/publication, session isolation, absolute budgets, durable recovery and identity
revocation to actual symbols/tests as code is introduced. Do not use advisory hooks as
gates. Produce versioned synthetic vectors for independent provider/consumer work.

Plan positive and negative authentication, resource isolation, crash/retry, audience
change, runtime restart and cancellation evidence. Bind real environment/provider modes
and downstream UAT applicability. Draft plans are not tests or permission to deploy.
