# llull-buzz

Reusable communication and agent-integration configuration, ports and adapters.

This initialization commit establishes a base branch for review. The proposed
bootstrap, public contracts, ADRs and assurance requirements are supplied in the
bootstrap pull request. No application, runtime or dependency is installed here.

This repository is not a fork of the Buzz application. License selection remains
an explicit project decision; no license grant is inferred from public visibility.
